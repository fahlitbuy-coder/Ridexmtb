RIDEX MTB - prototipo web instalable

CONTENIDO
- index.html: aplicación
- manifest.webmanifest y sw.js: base para instalar como PWA

IMPORTANTE
- El mapa usa teselas de OpenStreetMap y necesita internet.
- GPS necesita permiso del navegador y HTTPS (o localhost).
- La grabación usa geolocalización del navegador; mantén la app abierta.
- Exporta e importa GPX.
- No incluye automáticamente los senderos de Trailforks. Para añadirlos, importa archivos GPX obtenidos legalmente/mediante las opciones permitidas por Trailforks.
- El centro inicial del mapa es aproximado; permite ubicación GPS para centrarlo correctamente.
- Este ZIP es un prototipo web, no un binario nativo firmado para App Store o Google Play.

INSTALACIÓN
1. Descomprime el ZIP y publica la carpeta en un alojamiento HTTPS (por ejemplo, un hosting estático).
2. Abre la dirección HTTPS en Safari (iPhone) o Chrome (Android).
3. iPhone: Compartir > Añadir a pantalla de inicio.
4. Android: menú del navegador > Instalar aplicación / Añadir a pantalla de inicio.
